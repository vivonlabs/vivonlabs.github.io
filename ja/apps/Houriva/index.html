📱 Houriva
やさしい通知 · 時間どおりの通知 · ルーティン · 集中 · こころのケア

Hourivaは、決まった時間に届く短くてやさしい通知をお届けするリマインダーアプリです。
健康・集中・こころのケアなど、日常でつい忘れがちな小さなルーティンを、もっと軽やかで安心できる形で続けられるように作られています。
複雑なタスク管理や重い習慣トラッキングよりも、「今ほしいタイミング」に届く一度の通知に焦点を当てます。
主要な設定は基本的に端末内（ローカル保存）に保管され、アプリ内にはGoogle AdMobのバナー広告が含まれる場合があります。

※ Hourivaは日常のルーティンとセルフケアを支える補助的なアプリです。医療機器・医療サービス・緊急通報サービスではありません。

✨ 主な特長

  • ログインなしですぐ始められる
  • 時間帯に合うやさしいメッセージ
  • 健康 · 集中 · こころのケアのための繰り返し通知

👤 こんな方におすすめ

Hourivaは次のような方のために設計されています。

  • 水を飲む、ストレッチ、呼吸、姿勢チェックなど、小さな習慣を続けたい方
  • 複雑なToDoアプリより、軽くてシンプルな繰り返し通知を好む方
  • 一日の中で集中の切り替えが多い学生、会社員、在宅勤務の方
  • 健康・集中・こころのケア向けに、短くてやさしいリマインダーがほしい方
  • ログインや煩雑なアカウント設定なしですぐ始めたい方
  • 多機能よりも、「今必要な一度の通知」を大切にしたい方

Hourivaは「もっと頑張れ」と迫るアプリではなく、「今この瞬間を見逃さないように手伝う」アプリを目指しています。

🕐 Hourivaが役立つ瞬間

Hourivaは大きな計画より、日常のなかで見落としやすい「小さな行動のタイミング」に焦点を当てます。

  • 朝、一日をゆっくり始めたいとき
  • 水を飲む・ストレッチをいつも忘れてしまうとき
  • 仕事や学習のあいだで集中の流れを取り戻したいとき
  • 少し呼吸を整えたり、姿勢を見直したいとき
  • 夜、一日をもう少し穏やかに締めくくりたいとき

大切なのは巨大な計画より、必要な瞬間に届く短くてはっきりした通知かもしれません。

🔔 「やさしい通知」と「時間どおりの通知」に集中

多機能を一度に詰め込むより、長く使い続けられる二つの核に力を入れています。

やさしい通知

  • 機械的な通知の代わりに、その時間に合う短くてあたたかい文を届けます
  • 健康 / 集中 / こころ / デフォルト / カスタムのスタイルから選べます
  • 一日の流れを乱さないよう、やわらかいトーンで設計されています

時間どおりの通知

  • 指定した曜日・時刻・分に合わせた繰り返し通知
  • ホーム画面から簡単にオン / オフ
  • 日常のルーティンを自然に続けられるようサポート

Hourivaは単に「通知を送るアプリ」ではなく、一日のリズムをやさしくつなぐアプリを目指しています。

💬 時間帯に合うやさしいメッセージ

Hourivaは時刻を知らせるだけのアプリではなく、その時間帯と使い方に合う雰囲気のメッセージを届けます。

  • 朝は、一日をやわらかく始められるように
  • 午前は、集中の流れをつくれるように
  • 昼は、少しだけ呼吸を整えられるように
  • 午後は、リズムを取り戻せるように
  • 夕方と夜は、こころを静かに整えられるように

次のスタイルから、自分のルーティンに合う通知の雰囲気を選べます。

  • デフォルト
  • 健康
  • 集中
  • こころ
  • カスタム

つまり、同じ「通知」でも、自分に合う形で受け取れるよう設計されています。

メッセージの例

Hourivaは、時間と状況に合うやわらかい文でルーティンを支えます。

  • 朝：「今日も、ゆっくり始めて大丈夫です。」
  • 午前：「今から10分だけ集中するだけでも、流れが変わることがあります。」
  • 昼：「少し呼吸を整えて、体を伸ばしてみませんか。」
  • 午後：「リズムが乱れても、今からまた続ければ大丈夫です。」
  • 夜：「今日も十分にがんばりました。少し休んでも大丈夫です。」

⚙️ 主な機能

単純な通知機能にとどまらず、負担なく長く使えるルーティン体験を目指しています。

繰り返しスケジュール

  • 希望の曜日を選択
  • 希望の時間帯を選択
  • 分単位で時間どおりの通知を設定
  • 繰り返し通知を自動で維持

一度設定すれば、毎回自分で覚えていなくてもルーティンを続けられます。

通知スタイルの選択

  • デフォルト / 健康 / 集中 / こころ / カスタムに対応
  • 状況や気分に合うトーンを選べます
  • 日常の小さな行動を続けやすくする設計です

自分好みの通知体験

  • 通知音の設定
  • バイブレーションパターンの設定
  • 音声案内（TTS、Text To Speech）の利用
  • 試聴（プレビュー）に対応

強すぎず弱すぎず、自分にしっくりくる通知体験に調整できます。

すばやいスタート

  • ログイン不要
  • 会員登録不要
  • ローカル保存を基本とした設計
  • 短いオンボーディングのあと、すぐ使い始められる

Hourivaは「始めるまでに時間がかかるアプリ」ではなく、短時間で設定してすぐ使えるルーティンアプリを目指しています。

🔄 他のリマインダーアプリとの違い

Hourivaは機能の多さより、負担なく繰り返し使える体験を重視します。

  • 重い生産性管理より、軽やかで安心できる繰り返し通知
  • 冷たい機械的通知より、時間に合うやさしいメッセージ
  • 過剰な設定やアカウント構造より、すばやい開始とシンプルな操作
  • 「管理」より「続ける」に近いルーティン体験

つまりHourivaは、タスクを押しつけるアプリではなく、小さな行動を続けやすくするアプリに近いのです。

🔔 信頼できる通知設計

Hourivaは、繰り返し通知ができるだけ安定して届くよう設計されています。

  • 設定した曜日・時刻・分を基準に繰り返し通知を予約
  • 端末設定とOSの動作に応じて、アプリが起動していなくても通知が動作しやすい構造
  • Androidでは、正確なアラームや再起動後の復帰も考慮した設計
  • 通知権限・システム設定・バッテリー最適化の状態を確認しやすい設定の流れ
  • シンプルな設定と分かりやすい画面ですぐ使い始められる

※ 実際の通知の動作は、端末設定、通知権限、バッテリー最適化、集中モード、メーカー方針、再起動、時刻・タイムゾーンの変更、その他のOS条件によって異なる場合があります。

🧭 クイックスタートガイド

複雑な設定なしに、すばやく始められます。

  1. スタイルを選ぶ： デフォルト / 健康 / 集中 / こころ / カスタムから希望のスタイルを選択
  2. スケジュールを設定： 曜日・時刻・分を選択
  3. 通知を有効化： ホーム画面から通知を開始
  4. 細かく調整： 必要に応じて通知音・バイブ・音声案内（TTS）を設定
  5. ルーティンを続ける： 一日のなかで必要な瞬間にやさしい通知を受け取る

⚠️ ご注意

  • 一部のAndroid端末では、時間どおりの通知のために「正確なアラーム」権限の許可が必要な場合があります。
  • 一部の端末では、バッテリー最適化やメーカー方針により通知の動作が異なることがあります。
  • 再起動や時刻・タイムゾーン変更のあとは、通知の状態を一度確認することをおすすめします。
  • 通知音と音声案内は、端末の音量やシステム設定の影響を受ける場合があります。

🔐 プライバシーを優先した設計

日常のルーティンに関わるアプリだからこそ、複雑なアカウントよりシンプルで負担の少ない体験を優先します。

  • 主要な設定データはローカルに保存され、アカウントなしで利用できます
  • 氏名・メール・電話番号などの会員情報の入力なしで始められます
  • 繰り返しスケジュール、選択したスタイル、通知関連の設定は端末内保存を基本に保持されます
  • 中核の通知機能は、サーバーに依存しない動作を想定して設計されています
  • 通知の提供に必要な最小限の権限のみを求めます
  • 広告配信のため、Google AdMobおよび関連パートナーによって限定的な広告関連データが処理される場合があります

詳しくはプライバシーポリシーをご覧ください。

📢 広告について（Google AdMob）

開発・保守・継続的な運営のため、Hourivaはアプリ内にGoogle AdMobのバナー広告を表示する場合があります。

現在、ホーム画面の下部などにバナー広告が表示される場合があります。

広告の考え方

  • 主要な利用の流れを過度に妨げない範囲で運用します
  • ルーティン設定ややさしい通知の体験を損なわないよう、配置に配慮しています
  • 広告配信の過程で、Googleおよび関連パートナーが限定的な端末・広告関連データを処理する場合があります
  • お客様が設定した通知時刻、ルーティン内容、メッセージ本文を、当社が広告ターゲティング目的で直接販売したり、別の会員情報と結びつけたりすることはありません
  • 広告のパーソナライズの有無は、端末設定やGoogleの広告設定などによって異なる場合があります

広告の詳細はプライバシーポリシーもあわせてご確認ください。

🛡️ 通知と権限（Android）

安定した繰り返し通知のため、次の権限またはシステム機能を使用する場合があります。

正確なアラーム

  • 目的： 設定した時刻により正確に通知を届けるため
  • 範囲： 繰り返し通知機能にのみ使用
  • 設定： 一部端末では「正確なアラーム」権限の許可が必要な場合があります

通知権限

  • 目的： 端末上で通知を表示するため
  • 範囲： お客様が設定したルーティン通知の提供
  • 管理： いつでもシステム設定から変更できます

バッテリー最適化の例外

  • 目的： 一部端末で通知の取りこぼしを減らすため
  • 範囲： 通知の安定性向上を支援する設定
  • 管理： お客様ご自身が許可・変更できます

バイブレーションと起動後の復帰

  • 目的： バイブレーション通知の提供、および端末再起動後の予約通知の復帰
  • 範囲： お客様が設定した通知機能の提供にのみ使用
